# Public dashboard demo

Open `/dashboard/` on the public website. This is a static, independent copy of the dashboard client, with an authored fictional data fixture. It does not import the private server, runtime state, vault, credentials, contact, or messaging worker.

Home supports week/month views, credit details, and a saved apartment plan. Library opens monthly/weekly reports and lets visitors cancel fictional reminders. You shows a fictional profile and connector disclosures, plus browser-only check-in preference changes. Reset or reload restores the original fixture. No account, provider, or texting requests are made by this dashboard. The separately consented website chat remains isolated.

Both weekly category totals and daily bars sum to $210.09. October categories sum to $890 against a $1,000 example budget. Credit scores and report facts are authored examples, not a new live CRS pull. The apartment plan is an example proposal, not a new live CREAO run. Source files are in `netlify/public/dashboard` and `website/public/dashboard`.
